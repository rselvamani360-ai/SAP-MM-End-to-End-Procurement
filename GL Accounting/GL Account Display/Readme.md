# G/L Account Display

## Definition

G/L Account Display in SAP is used to view and review the master data and details of General Ledger accounts.

## Transaction Code

**T-Code:** `FS00`

## Process Flow

**G/L Account Creation → G/L Account Display → Review G/L Account Details**

## Purpose

G/L Account Display is used to view the existing G/L account information maintained in SAP.

## Key Information

- G/L Account Number
- Company Code
- Account Group
- Account Type
- Account Description
- Currency
- Control Data
- Tax Information
