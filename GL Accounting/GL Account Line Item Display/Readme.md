# G/L Account Line Item Display

## Definition

G/L Account Line Item Display in SAP is used to view the individual accounting line items posted to a G/L account.

## Transaction Code

**T-Code:** `FBL3N`

## Process Flow

**G/L Account Creation → G/L Account Posting → G/L Account Line Item Display → Review Accounting Entries**

## Purpose

The G/L Account Line Item Display is used to review the accounting postings recorded against a specific G/L account.

It helps to analyze document numbers, posting dates, amounts, document types, and other accounting details.

## Key Information

- G/L Account
- Company Code
- Document Number
- Assignment
- Document Type
- Document Date
- Posting Date
- Posting Key
- Amount
- Currency
- Clearing Document
- Text

## Practical Example

**G/L Account:** `251511`

**Description:** `CGST PAYABLE ACCOUNT 2.5`

**Company Code:** `6565`

The line items posted to the G/L account can be displayed and reviewed using the relevant selection criteria.
