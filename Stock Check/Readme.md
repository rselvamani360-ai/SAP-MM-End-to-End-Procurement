# Stock Check

## Definition

Stock Check in SAP MM is used to view the current stock quantity and availability of a material in a plant and storage location.

## Transaction Code

**T-Code:** `MMBE`

## Purpose

The MMBE transaction is used to check the stock overview of a material and understand the available stock at different organizational levels.

## Stock Overview

MMBE can be used to view stock information for a specific material across:

- Company Code
- Plant
- Storage Location
- Stock Type

## Procurement Flow

**Purchase Requisition → RFQ → Quotation → Vendor Comparison → Purchase Order → Goods Receipt (MIGO) → Stock Check (MMBE) → Invoice Verification (MIRO)**
