# Vendor Creation

## Definition

Vendor Creation in SAP MM is the process of creating and maintaining supplier master data required for procurement activities.

## Transaction Code

**T-Code:** `BP`

## Procurement Flow

**Business Partner Creation → Vendor Creation → RFQ → Quotation → Vendor Comparison → Purchase Order**

## Purpose

Vendor Creation is used to maintain the supplier information required for purchasing and other business transactions.

## Vendor Creation Process

1. Execute transaction code `BP`.
2. Create the Business Partner as an organization.
3. Enter the vendor's basic information.
4. Maintain address and contact details.
5. Assign the required supplier role.
6. Maintain company code data.
7. Maintain purchasing organization data.
8. Maintain the required payment and purchasing information.
9. Save the Business Partner.

## Key Information

- Business Partner Number
- Vendor Number
- Vendor Name
- Address
- Search Terms
- Country
- Region
- Postal Code
- Company Code
- Purchasing Organization
- Payment Terms
- Supplier Role
